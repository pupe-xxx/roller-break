# ROLLER BREAK

タイヤを転がして、盤の上の的を全部倒すパズル。ブラウザで動く。TypeScript + Vite + Canvas。
[web-game-template](https://github.com/pupe-xxx/web-game-template) から作った。STRATA の「転師」のタイヤを、1人用のパズルに切り出したもの。

## 遊び方

- 転師（オレンジの丸）のまっすぐ先のマスをタップすると、その向きにタイヤが転がる
- **軽いタイヤ**は、的を1つ倒して止まる
- **重いタイヤ**は、的を倒しながら進み続ける。撃てる回数はステージごとに決まっている
- **壁**に当たると、タイヤは1段削って止まる。濃い壁は1段、中に明るい六角形がある壁は2段
- ほかの転師に当たると止まる
- 転師が複数いる時は、転師をタップして撃つ転師を選ぶ
- 的を全部倒すとクリア。発射数が最少なら ★3、1発多いと ★2、2発多いと ★1。それでも倒しきれないと失敗

ステージは24個。最初の3つは遊び方を覚えるためのもの。クリアした一番先のステージの、2つ先まで遊べる。

## コマンド

| コマンド | すること |
|---|---|
| `npm run dev` | 手元で動かす |
| `npm test` | ルールの自動テスト。全ステージが解けることと、★3 の発射数が最少であることも確かめる |
| `npm run gen` | ステージを作り直す（`src/game/levels.gen.ts` を書き出す） |
| `npm run record` | 動作記録（`tests/golden/golden.json`）を取り直す |
| `npm run typecheck` | 型の検査（ルール側が画面に触れていないかも見る） |
| `npm run build` | 検査してから `dist/` に公開用のファイルを作る |

## フォルダ

```
src/
  main.ts    入口
  kit/       どのゲームでも使う共通部分（型のまま）
  game/      ルール。画面の処理に触れない
    hex.ts         六角形の盤の座標
    rules.ts       発射・クリアと失敗の判定・星の数
    solve.ts       総当たりで最少の発射数を求める
    levels.ts      ステージの一覧（最初の3つは手作り）
    levels.gen.ts  scripts/gen.ts が書き出したステージ
  ui/        描画と操作
    shell.ts       ステージ選択・結果・星の保存（ステージ制のパズルに共通の外枠）
    game.ts        このゲームの盤の描画とタップの処理
    hexview.ts     六角形の盤を描くための座標の計算
    i18n.ts        日本語と英語の切り替え（ブラウザの言語で決まる）
scripts/
  gen.ts     ステージを作る
  record.ts  動作記録を取り直す
tests/
```

## ステージの作り方

`scripts/gen.ts` が、乱数で盤を作り、総当たりで解いて、次の条件を満たすものだけ残す。乱数の種は固定なので、何度実行しても同じステージができる。

- 解ける。最少の発射数が、その段階の範囲に入っている
- 撃つ順番を選ぶ（どの順でも解けるステージは外す）
- 重いタイヤがあるなら、無いと最少では解けない
- 転師が複数いるなら、1人では最少で解けない

段階（盤の広さ・的と壁の数・最少の発射数）は `scripts/gen.ts` の `TIERS` にある。変えたら `npm run gen` → `npm run record`。

## 守ること

型の README と同じ。特に次の2つ。

- **`src/game` は画面に触れない。** `Math.random` も時計も使わない
- **ルールやステージを意図して変えたら、動作記録を取り直す（`npm run record`）。**

## 公開

`main` に push すると、テスト → ビルド → GitHub Pages への公開まで自動で進む。
ゲームサイト（Poki・CrazyGames など）の広告 SDK は入っていない。差し込み口は `src/kit/platform/`。やり直しと次のステージの前に、区切りの広告を呼ぶ作りになっている。
